# 一日一樹

一個在瀏覽器裡玩的種樹遊戲（世界之樹）。你只照顧一棵樹：澆水、施肥、疏水、除蟲，維持健康、水分、養分同抗風力。天氣跟你所在的真實天空（香港用天文台警告）；惡劣天氣會提早 12 小時倒數，可以先加固。揀一個賽季，喺限期前長到目標高度。

遊戲介面是香港書面粵語（繁體中文，`zh-Hant-HK`）。進度只存在這部裝置的 `localStorage`，沒有帳戶，也沒有後端。

## 畫面

樹種在一個浮喺海上的小草島上（圍欄、石頭、花、小溪、木橋），個島會隨生長階段擴建成樹種嘅原生地景觀，用 three.js 即時繪成低多邊形 3D 場景，由斜上方 45 度望落去。樹越長越高，鏡頭會慢慢升高、拉遠，令整棵樹一直留喺畫面入面；可以喺空白位置輕輕拖動轉角度。樹幹粗幼、枝數、樹冠大小跟住生長階段變；解鎖的動物會以細小 3D 模型成群出現。雨絲、風吹擺動、雲量、日夜光線（跟當地時間）同風暴變暗都會喺場景入面顯示。部機唔支援 WebGL 就會自動轉用簡化的 2D 畫面。

- 左上：天氣卡（溫度、天氣、明日預測；有風暴來會變紅提醒加固）。點一下睇一星期預報同加固。
- 右上：地點（可揀香港各區或者用所在位置）同設定（改名、畫質）。
- 右邊：樹木狀態卡（H/W/N/R 橫條，綠色區係最佳範圍，另有「除蟲」「疏水」快捷掣；點標題睇全部照顧動作），同埋高度尺（點一下睇賽季進度）。
- 底部：澆水、施肥、加固、圖鑑四個大掣。上面一條小把手係「成長日誌」，平時收埋；向上拖或者點一下拉開，向下掃或者再點一下收返。

## 怎樣玩（世界之樹規則）

1. 替樹起名，揀賽季同樹種：3 個月長到 20 米、6 個月 50 米、1 年 100 米。每個賽季有三個真實成樹高度相近嘅樹種可揀（見下面「樹種」）。每個賽季目標高度固定，唔使花資源擴建。
2. 四個指標：健康 H、水分 W（最佳 40–80）、養分 N（最佳 60–100，低過 30 營養不良）、抗風力 R（0–100）。
3. 每晚結算：`H 變化 = W 因素 + N 因素 − 天氣損傷 × (1 − R/100)`。W 喺最佳範圍 +5，唔喺 −10；N 60 以上 +5、30–59 為 0、低過 30 −10。每日用 10 養分，R 自然減 2。
4. 天氣事件唔疊加：同一日有幾個，只計基礎損傷最高嗰個同佢的副作用。晴天 0、毛毛雨 0、酷熱 10、暴雨／黑雨 20、初級颱風 30（R −40）、狂風雷暴 35（R −30）、高級颱風 60（R −80）。
5. 生長：健康 80 以上 ×1.5（有綠光）、50–79 ×1、20–49 ×0.2、低過 20 ×−0.5（斷枝縮短）。惡劣天氣損傷壓到基礎 25% 或以下，當日生長再 ×1.3。
6. 照顧：澆水 +20 W（每日 3 次）、疏水 −25 W（2 次）、施肥 +25 N（1 次）、除蟲。加固：打木樁 +15、綁防風繩 +12、修枝防風 +8（每樣每日一次，R 最多 100）。惡劣天氣會提早 12 小時倒數。
7. 健康跌到 0 會瀕死 24 小時；期間將 W、N 調返最佳範圍就救返（H 10）。枯死的樹變成養分地標，下一棵樹開局 +40 養分。
8. 健康連續 3 晚 90 以上，會有動物長駐（每隻每日 +2 養分）。完成賽季得徽章同能力；碳吸收量隨高度顯示（示意數值）。

每個樹種有獨立嘅程序化 3D 模型（輪廓、樹皮色、葉形），分五個生長階段：幼苗、小樹、青年樹、成年樹、巨樹（按樹種目標高度嘅 0／2.5／10／40／85%）。例如木棉成年開紅花、巨樹掛棉絮；銀杏成年轉金、巨樹落葉鋪地；紅杉巨樹有火疤同多個樹頂。

樹會跟天氣搖：晴天幾乎唔郁，有風、陣風會擺，暴雨、狂風雷暴、颱風擺得最勁。酷熱天會有一道柔和暖光由畫面右上角照落樹度：幾條淡淡嘅光柱加一團暖色光暈，慢慢一呼一吸咁變光暗，太陽光亦會轉暖、轉去右上方向；唔會閃白成個畫面（系統設定「減少動態」時光暈唔會呼吸，保持靜止）。

樹冠密度跟健康走：悉心照顧（健康高）嘅樹葉多、樹冠飽滿，仲會多一層內層葉填滿空隙；健康低就會疏落、部分葉團唔見咗，葉色轉黃。九個樹種喺健康好時都係滿冠（水杉加咗羽狀圓錐內冠同更多層枝葉，杏仁桉多咗主枝、葉團同頂冠）。

### 真實天氣

全部喺瀏覽器直接攞，冇後端、唔使 API 金鑰：

- **[Open-Meteo](https://open-meteo.com/)**：你所在位置的現時天氣、未來 12 小時同 7 日預報（雨量、陣風、天氣代碼）。失敗會再試兩次（429／伺服器錯誤會等一陣）。
- **[香港天文台開放數據](https://data.weather.gov.hk/weatherAPI/doc/)**（`lang=tc`，喺香港或附近、或者用香港預設位置時）：`warnsum` 現時警告、`rhrread` 最近氣溫站讀數同分區雨量、`fnd` 九天預報。天文台有 CORS，瀏覽器可以直接讀。
- **[BigDataCloud 反向地理編碼](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api)**：把座標變成地名（例如「沙田區」），每個位置只查一次。

次序：Open-Meteo（香港再加天文台實測）→ Open-Meteo 唔得就單用天文台 → 最近三日內成功過的記錄 → 全部失敗先用模擬天氣。天氣卡會寫明來源（「即時天氣・Open-Meteo／天文台」、「上次天氣 …」或「模擬天氣・撳一下重試」）。成功攞到的天氣會留 30 分鐘，期間重開唔會再查。定位 8 秒內冇回應或者被拒，就用香港的真實天氣。

喺香港，天文台的警告會直接變成遊戲天氣事件：酷熱天氣警告 → 酷熱；黃／紅雨 → 暴雨；黑雨 → 黑雨；雷暴警告或強烈季候風 → 狂風雷暴；一號／三號風球 → 初級颱風；八號或以上 → 高級颱風。

冇天文台信號時（香港以外），遊戲按 Open-Meteo 預報判斷：

- 暴雨：日雨量 25 毫米或以上（70 毫米或以上當黑雨）
- 狂風雷暴：雷暴天氣代碼，或陣風 62 km/h 或以上
- 初級颱風：陣風 88 km/h 或持續風 50 km/h 或以上；高級颱風：陣風 118 km/h 或持續風 63 km/h 或以上
- 酷熱：最高氣溫 33°C 或以上

### 開發者面板

開發版左邊有個扳手掣。可以切換「真實／手動天氣」、同時揀幾個事件（驗證唔疊加）、設定 12 小時預報、拉 H/W/N/R、跳去下一日即刻結算、觸發蟲害、重置存檔，並睇上次結算明細。另外可以預覽任何樹種同生長階段、另外揀島嶼階段（跟樹或者 1–5，睇到該樹種原生地景物清單）、強制搖擺程度（平靜到颱風）、觸發酷熱柔光、召喚指定動物、「鏡頭跟拍」某種動物做特寫、輪換動物、一鍵解鎖全部動物，同埋睇動物上限（組數、隻數、最大體型、而家幾多組）同畫面上有邊啲動物組。設定存喺獨立的 `sekai-tree-dev`。

關閉：`VITE_DEV_PANEL=0 npm run build`（或者喺 `.env.production` 寫 `VITE_DEV_PANEL=0`）。關閉時面板程式碼唔會打包入成品。

## v11：地上動物行得自然、用晒成個島、唔會重疊或者穿過石頭樹叢

- **原因**：v10 嘅漫遊範圍只係內圈（約圍欄一半）、目標只揀鏡頭嗰邊；下一步濕咗就即刻停低重揀目標，搵唔到直線乾路就每格重揀（原地抖）；跟隨者追住按領頭方向轉嘅隊形位，領頭一轉身就衝過其他動物，水邊縮隊形又會跳位；爬樹開始／完結、松鼠返屋企都會瞬移；動物之間同道具完全冇碰撞。
- **行走地圖**（`src/three/walkNav.ts`）：0.25 單位一格，分乾地／水／阻擋（圍欄外、山丘、樹幹、石頭、樹叢、樹蕨、細樹、石牆、屋、神社、燈籠、亭柱、平台、石級；草同花照行得過）。道具腳印喺 `habitat3d` 同花園度記錄，半徑跟道具系數縮放。兩個淨空距離場（行路／涉水）令大隻動物身體唔會貼住障礙或者水邊；Dijkstra 流場帶路繞過水同障礙，行向睇得到嘅最遠路點，所以唔會卡住。
- **漫遊目標**：喺圍欄內所有行得到嘅乾地均勻抽樣，再按「少去過」嘅地方同避開其他群體加權；涉水鳥偏向水邊；離開時行去最近嘅圍欄邊淡出。
- **移動**：seek + arrive 轉向、加速度限制、步態跟速度；永遠唔會瞬移（出生、搬位都用淡入淡出）；停低只係有意嘅休息（2.5–6.5 秒）。
- **碰撞**：空間雜湊做動物之間分隔（半徑按身長×動物系數），企定嘅會讓路；道具用精確圓形硬限制，行路前面預先閃避，唔會穿過。
- **量度**（`scripts/v11-tracks.mjs` 記錄每 0.05 秒位置，`scripts/v11-analyze.mjs` 計瞬移、停滯、重疊、穿道具、覆蓋率同熱圖；`scripts/v11-shots.mjs` 截圖同現場檢查）：瞬移 0、重疊同穿道具約 0，覆蓋率大約係 v10 嘅兩至三倍。輸出去 `/workspace/tree-game-shots/v11/`。

## v10：跟拍單一隻鳥、跟拍時轉鏡、「新」即時消失、細道具跟動物同比例、更多水

- **追拍單一隻**：跟拍一群飛緊嘅鳥／昆蟲時，隨機揀其中一隻，鏡頭貼住佢後面偏側飛（追拍鏡），每格跟住佢移動所以唔會甩出畫面，轉向時鏡頭順滑咁兜過去；會避開樹幹同樹冠（試幾個角度，唔得就拉近）。如果嗰隻鑽咗入樹冠睇唔到，約 1.4 秒後自動轉跟同群另一隻（飛緊嘅優先）；隻身一隻就鏡頭升高由上面望落去。
- **跟拍時轉鏡**：跟住任何動物時，單指（或滑鼠）左右拖曳會圍住佢轉（上下拖調高低），動物一直喺畫面中間，唔會取消跟拍、唔會平移；雙指捏合／滑鼠滾輪照樣可以拉近拉遠。轉鏡期間唔會自動改角度避樹，只會拉近。
- **「新」**：撳標記、到訪通知、動物清單或直接撳隻動物開始跟拍，嗰種動物即刻當「圖鑑已睇過」：標記、清單、通知同 🐾 紅點嘅「新」即時消失，圖鑑數字同步減少，並寫入存檔（重新載入仍然記得）。
- **細道具跟動物同比例**：石頭、灌木、乾草、蕨、樹蕨、蘆葦、背景細樹、花、草、踏腳石同小橋唔再跟個島一齊放大，改用同動物一樣嘅放大系數 `clamp((G/8)^0.4, 1, 3)`（真實尺寸 × 系數；1 島單位設計 ≈ 1 米），但唔會大過 v6 嘅樣（`propK = min(1, 系數 / 島比例)`）。個島愈大，道具愈細、數量愈多（密度 × 1/propK²，石／灌木上限 × 6、花草上限 × 8、細樹 × 3），全部係合併網格或 instancing，縮放喺 GPU 做（每件道具圍住自己落地點縮放，`src/three/propScale.ts`），樹長高時連續變化，唔使重建；只有比例變化超過約 25% 先重新佈置數量。大地形（山、山丘、懸崖、海蝕柱）、村屋／亭／庭院等建築、樹、島、水面同圍欄維持原本比例。
- **更多水**：花園加咗個池塘、條溪闊咗；外圍池塘大咗兼沿住島嘅圈拉長，湖（按地勢盡量大）、河（闊 1.15）、小溪（闊一倍，尾有水潭）、濕地同水灣都大咗；每個原生地每個階段都有水，巨樹階段一定有湖或者河（樟樹＝水塘、棉樹＝河同湖、榕樹＝魚塘、水杉＝河同湖、銀杏＝放生池同湖、雪松＝冰川河、紅杉＝潟湖、桉樹／花旗松＝湖）。行地動物照樣唔會落水，圍欄照樣避開水口，標記照常。樟樹水面佔陸地：幼苗 9.6%、3 米 7.0%、10 米 12.7%、45 米 20.1%；雪松 60 米 23.0%。

測試：`node scripts/v10-shots.mjs`（`ONLY=chase,orbit,seen,props,water,guard`）檢查追拍鏡跟住一隻（喺畫面中間、大小合適）、棲息鳥群唔會甩跟拍、拖曳轉鏡唔甩跟拍而且動物喺中間、滾輪改距離、跟拍後「新」全部消失兼存檔、道具比例等於動物系數、各階段水面、v8 保證同 v9 標記，截圖（連 v9 對比，需要 `BASE_V9` 指住 v9 build）輸出去 `/workspace/tree-game-shots/v10/`。

## v9：睇得到細小動物（標記、動態提示、到訪通知、動物清單、成群出現）

真實比例之下，巨樹全景入面嘅昆蟲同細雀得一兩個像素。v9 唔會將佢哋放大（v8 嘅統一放大系數不變），而係加提示：

- **全景標記**（`src/animalHud.ts`）：動物喺畫面上細過 10 像素，頭上就會出一個小圖釘（分類圖示＋顏色：雀鳥藍、哺乳類啡、蝴蝶粉紅、昆蟲橙、爬蟲綠、兩棲青綠，底下一點發光圓點指住隻動物）。一群動物只得一個標記，右上角寫隻數；相距少過 30 像素嘅標記會合併（「+N」），最多同時 10 個；壓住狀態卡、高度尺、日誌、按鈕嘅標記唔會顯示。放大到動物本身大過 22 像素，標記就會淡出。撳標記＝跟拍嗰群動物（同撳動物本身一樣）。
- **動態提示**（`src/three/motionHints.ts`）：細雀（體長 35 厘米以下）飛行時拖一條淡白色、會褪色嘅軌跡；昆蟲同蝴蝶有輕微閃光（固定畫面大小，所以遠睇都見到，近睇會淡出）；螢火蟲光點會輕輕呼吸。全部加埋得兩個 draw call。
- **到訪通知**：新一群動物嚟到，畫面頂會出「一群暗綠繡眼鳥飛咗嚟」、「兩隻獼猴行咗嚟」之類嘅通知，圖鑑未睇過嘅會標「新」；撳一下就跟拍佢哋。同時嚟幾群會合併成一條（「麻雀、菜粉蝶同中華蜜蜂嚟咗」），最多每 8 秒一條，4 秒後自動收埋。
- **島上動物清單**：左邊 🐾 掣（數字＝而家幾多群，有「新」品種會變紅），撳開列出島上每群動物嘅圖示、名、隻數、「新」（圖鑑未睇過）同「長駐」；撳一行就跟拍。
- **成群出現**：細雀同飛蟲（`flocky()`）揀嚟訪時機會高 2.5 倍，群組更大（小樹起碼一對），但一群最多佔該階段總隻數 40%；每階段嘅品種（組數）上限不變，總隻數上限提高到 6／12／24／40／60。同一群蝴蝶、蜜蜂、蜻蜓會一齊飛（共用一條路線，相距幾個身長），鳥群本身已經一齊飛。

測試：`node scripts/v9-shots.mjs`（`ONLY=markers,toast,flock`）檢查標記出現、唔壓住介面、放大淡出、撳標記／通知／清單會跟拍、通知合併、軌跡同閃光有畫、巨樹階段組數同隻數上限，同埋 v8 保證（統一放大系數、飛行上限樹高 + 5 米、圍欄、行地動物唔落水）同冇 console 錯誤，截圖輸出去 `/workspace/tree-game-shots/v9/`。

## v8：v6 比例、同一個動物放大系數、貼邊圍欄、紀錄目標

- **比例（`src/scale.ts`）**：成個 v6 場景（樹、島、原生地、圍欄、雲）用同一個倍數 k = G ÷ v6 模型高度 放大。樹頂仍然等於 G 米（高度尺同畫面一致），但樹同島嘅比例同 v6 一模一樣；代價係島代表嘅米數跟樹長大（幼苗時花園大約 2 米闊，120 米紅杉時半徑約 150 米）。v7 嗰種「樹大過島就另外放大島」已經取消。
- **動物：全部用同一個放大系數** `animalFactor(G) = clamp((G/8)^0.4, 1, 3)`：3 米 ×1、20 米 ×1.44、50 米 ×2.1、60 米 ×2.24、100 米 ×2.75、120 米 ×2.95、上限 ×3。同一刻所有動物之間嘅比例係真實嘅（水牛 2.8 米、獼猴 75 厘米、麻雀 14 厘米），個體差異只有 ±3%。
- **目標 = 樹種真實紀錄取整到 10 米**（上表），賽季日數唔變。舊存檔會自動換新目標（按賽季推斷舊目標 20／50／100 米），高度保留，「已突破」會重新計，日誌加一句「目標更新」。
- **圍欄貼住真正嘅島邊**：島邊係不規則形（`shoreRadius`），每條柱擺喺該方向島邊向內 0.16 島單位；地面高度用射線量度。水面或者山／懸崖位置會跳過唔起柱，欄杆只接相鄰兩條都存在嘅柱。實測九個樹種、幼苗到 160 米：冇一條柱出界，最大離邊 0.16–0.17 島單位。
- **飛行上限 = 樹高 + 5 米**（取消 80 米上限）。
- **更多水**：每個樹種每個階段都加咗池塘／小溪／湖／濕地／河，新景物「水灣」（開向島邊嘅靜水灣加瀑布同蘆葦）。行地動物揀目的地同行路時會避開水面（涉禽除外）。
- **更多動物**：總隻數上限 5／10／20／36／56（原本 3／6／12／22／36），鳥群倍數 0.8–2.3。

## v7：米制比例、冇高度上限、真實尺寸動物

- **比例：1 個單位 = 1 米**（`src/scale.ts`，`METRES_PER_UNIT = 1`）。`buildTree` 會量度模型頂點，再按比例縮放，令畫面上嘅樹頂高度剛好等於 G。實測 0.20／3／20／50／120／160 米全部吻合（v8 起由 `test/scale-v8.test.ts` 驗）。v6 用嘅係對數曲線：20 米樟樹只畫到 9 米，100 米紅杉只畫到 12.7 米。
- **冇上限**：季尾只會記低「賽季完成」並頒發徽章，棵樹會繼續長。高度計超過目標之後會自動延伸刻度，加一條「目標」刻線，同埋顯示「已突破目標／冇上限」。舊存檔入面嘅「完成」會自動轉換，繼續生長。
- **飛行上限 = min(80 米, 樹高)**：雀鳥、蝴蝶、蝙蝠喺空中嗰陣唔會高過樹頂或者 80 米。樹太矮嘅話，鳥會留喺枝頭。
- **圍欄跟住島邊**：每個階段都沿島嘅邊緣起欄（1.1 米高，大約每 2 米一條柱，留一個閘口）。棵樹大過個島嘅時候，島會跟住放大（islandK），圍欄同動物就保持 1:1。動物嘅活動範圍限喺欄內。
- **動物真實尺寸**：每種動物都喺 `data/animals.ts` 記低 `real.len`（體長）同 `real.span`（翼展），模型按呢啲數值縮放，例如綉眼鳥 11 厘米、麻雀 14 厘米、小白鷺 60 厘米（翼展 95 厘米）、黑鳶 60 厘米（翼展 1.5 米）、赤腹松鼠 40 厘米、獼猴 75 厘米、赤麂 1 米、水牛 2.8 米、蝴蝶翼展 5–25 厘米。
- **縮放同跟拍**：
  - 雙指捏合或者滑鼠滾輪可以向手指／游標所指嘅位置放大，最近去到 1.5 米，最遠可以睇晒成個島，過程會平滑過渡。放大咗之後，單指拖可以轉角度，雙指拖可以平移。
  - 撳一下動物，鏡頭就會跟住佢（跟拍鏡頭會自動避開樹幹、樹冠同石頭）。撳「返回全景」就會返去總覽。
  - 撳按鈕同拉起成長日誌嘅時候唔會觸發縮放。

## 本地執行

需要 Node.js 22 或更新。

```bash
npm install
npm run dev
```

開發伺服器預設在 [http://127.0.0.1:4327](http://127.0.0.1:4327)。

```bash
npm test
npm run build
npm run preview
```

`npm run build` 會先做型別檢查，再輸出靜態檔。成品在 **`dist/`**。把 `dist` 裡面的檔案放到任何靜態網站的根目錄即可（例如物件儲存、GitHub Pages、Render Static Site）。資源路徑是相對的，不需要伺服器端程式。
