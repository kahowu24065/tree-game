# 一日一樹

一個在瀏覽器裡玩的每日種樹遊戲。你只照顧一棵樹：澆水、施肥、捉蟲、修剪。樹健康、變大之後，會有雀鳥、松鼠和其他小動物搬進來。天氣跟你所在的真實天空；如果預報有暴雨、強風或颱風級陣風，可以先加固，捱過就有額外生長。

遊戲介面是香港書面粵語（繁體中文，`zh-Hant-HK`）。進度只存在這部裝置的 `localStorage`，沒有帳戶，也沒有後端。

## 畫面

樹種在一個浮喺海上的小草島上（圍欄、石頭、花、小溪、木橋），用 three.js 即時繪成低多邊形 3D 場景，由斜上方 45 度望落去。樹越長越高，鏡頭會慢慢升高、拉遠，令整棵樹一直留喺畫面入面；可以喺空白位置輕輕拖動轉角度。樹幹粗幼、枝數、樹冠大小跟住生長階段變；解鎖的動物（雀鳥、鵲鴝同巢裡的蛋、松鼠、蝴蝶、赤麂等）會以細小 3D 模型出現。雨絲、風吹擺動、雲量、日夜光線（跟當地時間）同風暴變暗都會喺場景入面顯示。部機唔支援 WebGL 就會自動轉用簡化的 2D 畫面。

- 左上：天氣卡（溫度、天氣、明日預測；有風暴來會變紅提醒加固）。點一下睇一星期預報同加固。
- 右上：地點（可揀香港各區或者用所在位置）同設定（改名、畫質）。
- 右邊：樹木狀態卡（高度、健康度、樹冠、根系，另有「捉蟲」「修剪」快捷掣；點標題睇全部照顧動作），同埋高度尺（當前高度、下一階段高度；點一下睇里程）。
- 底部：澆水、施肥、加固、圖鑑四個大掣。上面一條小把手係「成長日誌」，平時收埋；向上拖或者點一下拉開，向下掃或者再點一下收返。

## 怎樣玩

1. 替樹起個名。
2. 每日做幾件小事就夠，每樣每日一次。落雨不用澆水；酷熱時泥土會快些乾。
3. 點天氣卡或「加固」看未來七日。遊戲會標出暴雨、強風、颱風級和酷熱。
4. 嚴重天氣來臨前，可以打木樁、綁防風繩、修枝防風。颱風最好三樣都做，強風兩樣，暴雨一樣已經有用。那天過了之後先結算：準備足夠就捱過並長多一截；準備不足會掉健康，也可能拗斷一枝。樹不會因此枯死。
5. 「圖鑑」收集住在樹上的動物。「里程」把樹的高度跟真人、街燈、舊唐樓、尖沙咀鐘樓、將軍樹和海波龍比較。

幾日沒打開也可以。回來時樹會口渴、健康下降，但仍會按過去的日子慢慢長高。

位置只用來向 [Open-Meteo](https://open-meteo.com/) 查天氣（不需要 API 金鑰）。若拒絕定位，會用香港作預設。天氣更新失敗時，會沿用上次記錄；如果從未成功，就先當作平靜天氣，遊戲仍然可以玩。

這些是遊戲自己的門檻，不是香港天文台的正式警告：

- 暴雨：預測日雨量 25 毫米或以上
- 強風：陣風 62 km/h 或以上，或持續風 41 km/h 或以上
- 颱風級：陣風 118 km/h 或以上，或持續風 63 km/h 或以上
- 酷熱：最高氣溫 33°C 或以上

在網址加上 `?debug=1` 會出現「測試」按鈕，可以模擬晴、雨、酷熱、暴雨、強風、颱風，加入一場預報，快進一日，或把樹長到下一階段。用來在風平浪靜的日子示範風暴。

## 本地執行

需要 Node.js 22 或更新。

```bash
npm install
npm run dev
```

開發伺服器預設在 [http://127.0.0.1:4327](http://127.0.0.1:4327)。

```bash
npm test
npm run build
npm run preview
```

`npm run build` 會先做型別檢查，再輸出靜態檔。成品在 **`dist/`**。把 `dist` 裡面的檔案放到任何靜態網站的根目錄即可（例如物件儲存、GitHub Pages、Render Static Site）。資源路徑是相對的，不需要伺服器端程式。

## 樹會記得甚麼

`localStorage` 鍵名是 `yiri-yisyu-v1`（遊戲）、`yiri-yisyu-weather`（上次天氣）、`yiri-yisyu-place`（揀咗的地點）和 `yiri-yisyu-quality`（畫質）。清除網站資料就等於重新種一棵樹。

## 截圖同自動測試

`scripts/` 入面有用 Playwright 的腳本（先 `npm run build`，再用任何靜態伺服器喺 4327 埠開 `dist/`，另外要 `npx playwright install chromium`）：

- `node scripts/playtest.mjs`：功能檢查（照顧、日誌、風暴、圖鑑、地點、存檔）。
- `node scripts/shots-v2.mjs`：輸出手機同桌面截圖，並錄一段鏡頭隨樹升高的影片。
